## 그림 교체
`img/` 폴더에 같은 이름의 PNG가 있으면 코드로 그린 임시 그림 대신 그 그림을 씁니다.
지금은 주인공 8, 일반·엘리트 몬스터 28(겉모습), 보스 10, 아이콘 18장이 그림(PNG)으로 들어 있습니다. 잡몹은 종류마다 겉모습 2~4가지 중 무작위로 나오며(`js/data.js`의 `D.SKINS`), 행동·능력치는 같습니다.
새 그림을 넣으려면 `js/art.js`의 `IMG_LIST`에 이름과 크기를 추가합니다.
초록 배경 그림을 자르는 도구: `python3 tools/cutout.py 원본.png 이름1,이름2,... --grid 3x2 --flip 뒤집을이름 --out img` (격자 칸 순서대로 이름, 빈 칸은 skip)

## 밸런스 도구
- `node tools/sim.js 판수 챕터 강화레벨`: 자동 플레이 봇으로 측정합니다.
  - 사람처럼 반응을 늦추려면 앞에 `HUMAN=8 ERR=1.4`를 붙입니다.
  - 어려움 난이도는 `HARD=1`, 연장전까지 하려면 `OT=1`, 주인공 레벨은 `HLV=5`, 백귀야행은 챕터 자리에 `6`(주간 조건은 `WK=rush` 등)을 씁니다.
- `tools/sweep.sh`: 챕터별 권장 강화 레벨에서 한 번에 측정합니다.
- 숫자는 전부 `js/data.js`에 있습니다.

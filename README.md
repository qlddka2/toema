# 퇴마 서바이버 (가제) · v2.2

좀비가 된 짐승과 동양 신화 속 괴수를 물리치는 서바이버 게임입니다. 웹 브라우저(폰·PC)에서 바로 실행되고, 홈 화면에 앱처럼 설치할 수 있습니다(PWA).

## 볼륨
- **주인공 6명**: 처음에는 2명이 열려 있고, 4명은 조건을 채우면 해금됩니다.

  | 주인공 | 유형 | 시작 무기 | 특성 | 해금 조건 |
  |---|---|---|---|---|
  | 대성 | 근거리 | 여의봉 | 근접 피해 +20% | 처음부터 |
  | 우치 | 원거리 | 부적 | 공격 간격 -5% | 처음부터 |
  | 바리 | 지원 | 무령(방울) | 초당 체력 회복 +0.5 | 1장 클리어 |
  | 길동 | 기동 | 비도 | 금화 +20% | 누적 처치 3,000 |
  | 강림 | 술법 | 혼불 | 경험치 +10% | 2장 클리어 |
  | 설문 | 수호 | 지진 | 공격 범위 +15% | 3장 클리어 |

- **무기 12종**: 무기마다 진화 짝이 되는 패시브가 정해져 있습니다. 무기를 5레벨까지 올리고 짝 패시브를 가진 채 보물 상자를 열면 진화합니다. 신궁(가장 단단한 적을 꿰뚫는 화살)·호리병(적을 빨아들이는 소용돌이)은 v2.2에서 추가됐습니다.
- **세트 효과 3종**: 같은 계열 무기를 2개·3개 모으면 보너스가 켜집니다.

  | 세트 | 무기 | 2개 | 3개 |
  |---|---|---|---|
  | 도술 | 부적·낙뢰부·혼불·호리병 | 공격 간격 -8% | 치명타 확률 +10% |
  | 무예 | 여의봉·비도·지진·신궁 | 피해 +10% | 넉백 +50%, 치명타 피해 +50% |
  | 법구 | 염주·금강결계·무령·파초선 | 공격 범위 +10% | 초당 체력 회복 +1 |

- **패시브 10종**: 근력, 단전, 체력, 경공, 흡기, 회춘, 철갑, 행운, 천리안(투사체 속도·사거리), 혈기(처치 시 회복)
- **유물 8종**: 우두머리를 쓰러뜨리면 3개 중 하나를 고릅니다(한 판 최대 3개).
- **진(眞) 각성**: 주인공의 시작 무기를 진화시킨 뒤 25레벨 이상에서 보물 상자를 열면 그 주인공만의 2차 각성.
- **주인공 성장**: 금화로 Lv 1~10. 레벨마다 피해 +2%·체력 +3%, 5·10레벨 고유 특성.
- **연장전**: 최종보스 처치 후 계속 싸우기를 고르면 1분마다 강해지는 적을 버티며 점수(1초당 40)·금화를 쌓습니다.
- **백귀야행(무한 모드)**: 보통 5장 클리어 후 해금. 1~5장을 6분씩 지나며 우두머리 10마리, 이후 끝없이. 매주 월요일 바뀌는 주간 조건과 주간 랭킹.
- **보옥**: 무기·패시브를 다 올리면 레벨업·상자에서 끝없이 나오는 작은 능력치.
- **챕터 5개**: 챕터마다 보통·어려움 2단계라 총 10스테이지이고, 한 판은 10분입니다.

  | 챕터 | 중간보스 | 최종보스 |
  |---|---|---|
  | 1장 버려진 산골 | 검치호 | 구미호 |
  | 2장 썩은 늪 | 철갑 코끼리 | 이무기 |
  | 3장 얼어붙은 고개 | 타락한 해태 | 백호 |
  | 4장 불타는 산사 | 화서 | 주작 |
  | 5장 검은 바다 | 현무 | 청룡 |

- **보스 10종**: 돌진, 탄막, 유도탄, 순간이동, 발구르기, 낙하 공격, 불길 흔적, 소환 같은 패턴을 섞어 씁니다. 체력이 절반 아래로 떨어지면 분노 상태가 됩니다.
- **보상 체계**
  - 영구 강화 10종
  - 업적 24개
  - 일일 임무: 매일 3개 + 모두 완료 보너스
  - 7일 출석
  - 챕터 첫 클리어 보너스
  - 비급 도감
- **광고 자리**: 부활, 금화 2배, 다시 뽑기. 지금은 실제 광고 대신 3초 대기 화면을 띄웁니다. 광고 제거 결제($1.99)는 버튼만 있습니다.
- **온라인 랭킹**: 챕터 × 난이도별로 따로 매깁니다. 맞수와 같은 계정을 씁니다.

## 올리는 방법 (GitHub Pages)
1. 저장소 `toema`에 이 폴더의 파일을 전부 올립니다(덮어쓰기).
2. Settings → Pages → `main` / `(root)`
3. 주소: `https://qlddka2.github.io/toema/`
4. 업데이트할 때마다 `sw.js`의 `VERSION` 값을 올려 주세요.

## 랭킹 (Supabase)
- **v2.2 업데이트 때 `supabase/survivor.sql`을 SQL Editor에서 한 번 다시 실행하세요.** 연장전 점수와 백귀야행 주간 랭킹(챕터 번호 1000+주 번호)이 추가됐습니다. 기존 기록은 그대로 남습니다.
- 어려움 난이도는 챕터 번호+10으로 기록됩니다.
- Authentication → URL Configuration → Redirect URLs에 `https://qlddka2.github.io/toema/` 추가.

## 그림 교체
`img/` 폴더에 같은 이름의 PNG가 있으면 코드로 그린 임시 그림 대신 그 그림을 씁니다.
지금은 주인공 6, 일반·엘리트 몬스터 8, 보스 10, 아이콘 18장이 모두 그림(PNG)으로 들어 있습니다. 3~5장 몬스터는 1·2장 그림에 색만 덧칠해서 씁니다.
새 그림을 넣으려면 `js/art.js`의 `IMG_LIST`에 이름과 크기를 추가합니다.
초록 배경 그림을 자르는 도구: `python3 tools/cutout.py 원본.png 이름1,이름2,... --grid 3x2 --flip 뒤집을이름 --out img` (격자 칸 순서대로 이름, 빈 칸은 skip)

## 밸런스 도구
- `node tools/sim.js 판수 챕터 강화레벨`: 자동 플레이 봇으로 측정합니다.
  - 사람처럼 반응을 늦추려면 앞에 `HUMAN=8 ERR=1.4`를 붙입니다.
  - 어려움 난이도는 `HARD=1`, 연장전까지 하려면 `OT=1`, 주인공 레벨은 `HLV=5`, 백귀야행은 챕터 자리에 `6`(주간 조건은 `WK=rush` 등)을 씁니다.
- `tools/sweep.sh`: 챕터별 권장 강화 레벨에서 한 번에 측정합니다.
- 숫자는 전부 `js/data.js`에 있습니다.

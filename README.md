# 퇴마 서바이버 (가제) · 프로토타입 v0.1

좀비가 된 짐승과 신화 속 괴수를 물리치는 동양풍 서바이버 게임입니다. 웹 브라우저(폰·PC)에서 바로 실행됩니다.

## 들어 있는 것
- **주인공 2명**
  - 대성: 근거리, 여의봉 휩쓸기
  - 우치: 원거리, 부적 투척
- **챕터 2개 (각 10분)**
  - 1장 버려진 산골: 중간보스 검치호, 최종보스 구미호
  - 2장 썩은 늪: 중간보스 불가사리, 최종보스 이무기. 1장을 클리어하면 열림
- **무기·패시브**
  - 무기 6종: 여의봉, 부적, 낙뢰부, 염주, 금강결계, 파초선
  - 패시브 6종
  - 각각 5레벨, 무기·패시브 슬롯 각 4칸
- **판 안의 성장**: 레벨업할 때 3개 중 1개를 고름(공격 수단 최소 1개 보장), 보물 상자, 다시 뽑기
- **판 밖의 성장**: 금화로 영구 강화 6종
- **보스전**: 등장하면 결계(원형 경기장)에 갇힘. 빨간 표시는 공격 예고
- **광고 자리** (지금은 3초 대기 화면으로 대신함): 부활 1회, 금화 2배, 다시 뽑기
- **온라인 랭킹**: 챕터별 최고 점수. 맞수와 같은 Google 계정과 닉네임을 씀

## 조작
- 폰: 화면 아무 곳이나 누르고 끌기
- PC: WASD 또는 방향키
- 공격은 자동, ESC는 일시정지

## 올리는 방법 (GitHub Pages)
1. 새 저장소(예: `toema`)를 만들고 이 폴더의 파일을 전부 올립니다.
2. Settings → Pages → Branch: `main` / `(root)` 로 저장합니다.
3. 주소: `https://qlddka2.github.io/toema/`

## 랭킹 켜기 (Supabase, 맞수와 같은 프로젝트)
1. SQL Editor → New query → `supabase/survivor.sql` 내용을 통째로 붙여넣고 Run.
2. Authentication → URL Configuration → Redirect URLs 에 `https://qlddka2.github.io/toema/` 추가.
   이걸 빼먹으면 로그인 후 맞수 쪽으로 돌아갑니다.
3. 끝. 맞수에 로그인해 둔 상태면 같은 사이트라 로그인이 이어집니다.

## 랭킹 구조
- 점수는 10×생존초(최대 600) + 처치 수 + 중간보스 1,500 + 클리어 5,000 + 빠른 보스 처치 보너스((180−보스 처치 초)×20)입니다.
- 판을 시작할 때 서버가 시각을 기록하고, 끝날 때 다음을 확인합니다.
  - 게임 시간이 실제로 흐른 시간보다 길지 않은지
  - 처치 수가 생존 시간에 비해 말이 되는지
  - 클리어 조건(10분 이상 생존 + 중간보스 처치)을 채웠는지
- 점수는 서버가 다시 계산합니다. 같은 판은 두 번 기록되지 않고, 10분에 30판 넘게 시작하면 막힙니다.
- 챕터마다 개인 최고 기록만 남깁니다(`sv_best`).
- 포기한 판은 기록되지 않습니다.

## 밸런스 손보기
숫자는 전부 `js/data.js`에 있습니다(무기 수치, 적 체력·속도, 보스 체력, 웨이브 스폰량, 강화 비용).
`node tools/sim.js 20 1 0`을 실행하면 자동 플레이 봇이 판을 돌려 클리어율을 보여 줍니다. 인자는 판 수, 챕터, 강화 레벨 순서입니다.
`HUMAN=8 ERR=1.4`를 앞에 붙이면 반응이 느리고 조작이 부정확한 사람처럼 플레이합니다.

## 파일
- `index.html`: 화면·스타일
- `js/data.js`: 모든 수치
- `js/core.js`: 게임 규칙(화면과 분리)
- `js/art.js`: 코드로 그리는 그림
- `js/app.js`: 화면 그리기·조작·메뉴
- `js/rank.js`: 온라인 랭킹
- `config.js`: Supabase 공개 키
- `supabase/survivor.sql`: 랭킹 서버
- `tools/`: 밸런스 시뮬레이터·그림 확인용
